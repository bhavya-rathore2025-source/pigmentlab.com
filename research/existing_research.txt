3. COMPETITOR AUDIT: COLOR WHEEL (Gradients.app /wheel)
--------------------------------------------------------------------------------
Features of Gradients.app Color Wheel:
- Interactive circular color picker.
- Supports standard color palette presets:
  * Complementary (opposite colors)
  * Analogous (adjacent colors)
  * Triadic (equilateral triangle, 3 colors)
  * Tetradic / Square (4 colors)
  * Split-Complementary
  * Monochromatic
- Displays HEX codes for generated palette points.

CRITICAL WEAKNESSES & USER PAIN POINTS:
[X] Weakness 1: Digital RGB Wheel vs. Traditional Artistic RYB Wheel
    Gradients.app uses digital RGB/HSL hue angles.
    In digital RGB: Red is opposite Cyan, Blue is opposite Yellow.
    In traditional art & design theory (Goethe / Itten RYB wheel):
    Red is opposite Green, Blue is opposite Orange, Yellow is opposite Purple.
    Art students, painters, interior decorators, and fashion creators get
    frustrated because the color palettes on digital wheels do not match
    physical reality or classic design textbooks.
    -> OUR ADVANTAGE: A 1-click toggle: "Digital (RGB/Web)" vs. "Klassischer Farbkreis nach Itten (RYB)".
       This directly targets and dominates the German search cluster for "farbkreis nach itten"
       (>1,000/mo Easy) and "farbkreis itten", which Gradients.app completely fails to serve!


[X] Weakness 2: Zero Contrast & Accessibility Scoring (WCAG)
    When users generate a 3-color or 5-color palette, they have no idea if
    Color A can be used as text on top of Color B.
    Adobe Color has an accessibility tab, but Gradients.app completely lacks one.
    -> OUR ADVANTAGE: Automatic real-time WCAG 2.1 contrast matrix (AA / AAA Pass/Fail badge)
       for all generated combinations.

[X] Weakness 3: No Shade, Tint & Tone Matrix
    Gradients.app only gives 1 pure saturated hex per palette node.
    Real designers need the tints (mixed with white), shades (mixed with black),
    and tones (mixed with grey) to build a realistic UI or painting.
    -> OUR ADVANTAGE: Click any palette color to expand its 9-shade scale (100 to 900).

[X] Weakness 4: No Color-Blindness Simulation
    8% of men and 0.5% of women have color vision deficiency (Protanopia, Deuteranopia, Tritanopia).
    Gradients.app cannot simulate how color-blind users perceive the wheel.
    -> OUR ADVANTAGE: 1-click vision simulator toggle.

[X] Weakness 5: Weak Developer & Designer Exports
    Only allows copying raw HEX codes one by one.
    -> OUR ADVANTAGE: 1-click copy for Tailwind CSS config, CSS variables, and SVG palette download.

4. COMPETITOR AUDIT: COLOR MIXER (Gradients.app /mix)
--------------------------------------------------------------------------------
Features of Gradients.app Color Mixer:
- Mixes up to 8 colors together.
- Weight / proportion sliders.
- Live mixed swatch preview with HEX and RGB output.

CRITICAL WEAKNESSES & USER PAIN POINTS:
[X] Weakness 1: The "Muddy Grey" Additive RGB Blending
    Gradients.app averages RGB channels. Mixing Blue + Yellow produces a dirty,
    washed-out brownish grey instead of clean Green.
    -> OUR ADVANTAGE: Subtractive (RYB / Kubelka-Munk paint approximation) toggle
       so mixing Blue + Yellow produces vibrant Green like real paint.

[X] Weakness 2: No Modern OKLCH / CSS color-mix() Syntax
    Modern CSS (Baseline 2024+) natively supports:
    "color-mix(in oklch, #3b82f6 40%, #ef4444 60%)".
    Gradients.app gives zero modern CSS snippets.
    -> OUR ADVANTAGE: Live CSS color-mix() code generator ready to paste into modern stylesheets.

[X] Weakness 3: No Real-World Context Preview
    Only shows a sterile flat colored box.
    -> OUR ADVANTAGE: Live component preview (see the mixed color on an interactive
       button, badge, card, and dark/light background).

[X] Weakness 4: Zero Accessibility & Contrast Checking (WCAG)
    When a user mixes colors, Gradients.app gives no indication whether text placed
    on top of the resulting mixed color will be readable or legally accessible.
    There is no WCAG AA / AAA contrast calculator or black vs. white text preview.
    -> OUR ADVANTAGE: Real-time WCAG contrast ratio score (e.g. 4.5:1 / 7:1) showing
       whether white or black text passes AA/AAA on top of the mixed color.

5. MVP ACTION PLAN & ARCHITECTURE (Target Domain: pigmentlab.com)
--------------------------------------------------------------------------------
TOOL 1: The Core Color Mixer (Route: /mix)
- Mode Switcher:
  * Mode 1: [ 🎨 Real Paint & Pigments (RYB) ] - DEFAULT
    - Uses true subtractive pigment physics (Kubelka-Munk / Spectral.js / RYB).
    - Blue + Yellow = Vibrant Green (#2E8B57 / #168A35).
    - Red + Green = Rich Earthy Brown (#5C3317).
    - Red + Yellow + Blue = Deep Brown / Black.
    - Targets: Painters, crafters, DIY wall painters, teachers, art students.
  * Mode 2: [ 💻 Modern Web & CSS (OKLCH) ]
    - Uses modern 2024+ CSS perceptual color space (no brightness loss/clipping).
    - Output: Live CSS "color-mix(in oklch, ...)" code generator.
    - Targets: Web designers, Tailwind developers, UI/UX creators.
  * Mode 3: [ 🖥️ Classic Digital (RGB) ]
    - Standard computer screen linear RGB channel averaging.
    - Targets: Programmers, game developers, shader coders.
  * Mode 4: [ 🖨️ Print & Inks (CMYK) ]
    - Subtractive ink layering for physical print & packaging designers.
- Inputs: 2 to 6 color inputs with percentage proportion sliders (0-100%).
- Quick Presets: Artist oil tubes (Ultramarine Blue, Cadmium Yellow, Crimson Red, Titanium White).
- Live Previews: Resulting color swatch + interactive UI mockup (button, card, badge, light/dark text).
- Real-Time Accessibility: WCAG 2.1 Contrast Ratio score (AA / AAA Pass/Fail for white & black text).
- Exports: 1-click copy for HEX, RGB, HSL, CSS color-mix(), Tailwind config object.
- SEO: Dedicated WebApplication + FAQPage JSON-LD schema for Google Rich Results.

TOOL 2: The Johannes Itten Artist Color Wheel (Route: /color-wheel)
- Visual Canvas: Interactive circular wheel with drag handles.
- Mode Switcher:
  * Mode A: [ 🎨 Klassischer Itten Farbkreis (RYB) ] - Bauhaus 12-hue artist wheel
    (Red opposite Green, Blue opposite Orange, Yellow opposite Purple).
  * Mode B: [ 💻 Digital Screen Wheel (RGB / Web) ] - Standard screen hue wheel.
- Palette Presets: Complementary, Monochromatic, Analogous, Triadic, Tetradic, Split-Complementary.
- Features: Real-time WCAG contrast score between palette nodes + 9-step tint/shade generator (100 to 900).
- CVD Simulator: Protanopia, Deuteranopia, Tritanopia, Monochromacy.
- Exports: 1-click CSS Variables (:root { --color-1: ... }), Tailwind, and SVG palette download.
- SEO: Dedicated WebApplication + FAQPage JSON-LD schema for Google Rich Results.

PORTAL: Brand Homepage (Route: /)
- Purpose: Pure brand portal explaining the physics, benefits, and advantages of PigmentLab.
- Zero Keyword Cannibalization: Does not target "color wheel" or "color mixer" head terms in title/H1.
- Features: Side-by-side RGB vs Kubelka-Munk comparison, USP grid, dual CTA cards to /mix and /color-wheel.
- SEO: WebSite + Organization schema.

8. BEST JAVASCRIPT LIBRARIES FOR RYB & PAINT BLENDING (100% FREE / MIT LICENSE)
--------------------------------------------------------------------------------
1. FOR THE COLOR MIXER (Realistic Paint Pigment Mixing):
   - Spectral.js (npm: spectral.js | GitHub: r-wasm/spectral.js) [TOP PICK]
     * License: MIT (100% free for commercial use and AdSense sites).
     * Physics: Uses Kubelka-Munk theory (physical paint pigment absorption).
     * Behavior: Blue + Yellow = Vibrant Green. Red + Green = Rich Brown.
     * Code: spectral.mix('#002185', '#fcd300', 0.5, spectral.HEX)
     * Why not Mixbox? Mixbox is great but has a restrictive CC-BY-NC non-commercial
       license. Spectral.js is fully MIT open-source and ready for commercial sites.
   - ryb-color-mixer (npm: ryb-color-mixer | GitHub: camme/ryb-color-mixer)
     * License: MIT.
     * Pure lightweight JS implementation of physical subtractive paint blending.

2. FOR THE COLOR WHEEL (Johannes Itten RYB Wheel):
   - RYBitten (GitHub: meodai/RYBitten)
     * License: MIT.
     * Specifically designed around Johannes Itten's classical Bauhaus RYB color wheel.
     * Translates classical Itten pigment angles to digital RGB swatches seamlessly.
   - ryb (GitHub: bahamas10/ryb)
     * License: MIT.
     * Interactive RYB color wheel generator with divisions, rings, and palettes.

11. DOMAIN PIVOT & KEYWORD CANNIBALIZATION FIX (PIGMENTLAB.COM)
--------------------------------------------------------------------------------
PROBLEM IDENTIFIED:
- The domain "realcolormixer.com" pigeonholed the entire site as a mixer only.
- Google search algorithm checks query-domain fit: a user searching "color wheel" is far
  less likely to click realcolormixer.com, hurting CTR and rankings.
- Putting the Color Mixer on the homepage (/) created keyword cannibalization between
  the wheel and the mixer.

SOLUTION EXECUTED:
1. Rebranded to PigmentLab (pigmentlab.com).
   - "Pigment" conveys real paint/subtractive physics (Kubelka-Munk & Itten RYB).
   - "Lab" establishes an umbrella brand (like Coolors or Paletton) for multiple tools.
2. New 3-Page Route Architecture:
   - Route / (Homepage): Brand portal showcasing physics, benefits, and advantages.
     Zero "color wheel" or "color mixer" head keywords in title/H1 (No cannibalization).
   - Route /mix: Dedicated Color Mixer tool (owns 100% of mixer keywords).
   - Route /color-wheel: Dedicated Color Wheel tool (owns 100% of wheel keywords).
3. Removed "Harmony" Jargon:
   - "Harmony" was internal designer jargon with 0 search volume in Ahrefs data.
   - Replaced across all titles, H1s, and copy with real search queries:
     "Color Wheel Picker", "Color Palette Generator", "Complementary Color Wheel".
